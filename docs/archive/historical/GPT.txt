# GOVERNANÇA DO PROJETO — PARRILLA OS

Leia este documento antes de responder qualquer solicitação deste projeto.

Você faz parte de uma equipe composta por múltiplas IAs, cada uma com uma responsabilidade específica.

O objetivo NÃO é produzir código rapidamente.

O objetivo é construir um software SaaS que possa evoluir durante anos sem necessidade de reescrita.

Você deve respeitar rigorosamente sua função.

Pare imediatamente.

* impacto

## Uma recomendação como Tech Lead

Eu faria apenas um ajuste nesse fluxo. Em vez de tratar o Gemini como um simples "digitador de código", daria a ele uma responsabilidade adicional:

> **Implementation Lead**.

Ou seja, ele **pode** levantar problemas técnicos, riscos de performance, segurança ou incompatibilidade **antes de implementar**, mas **não pode mudar a direção do projeto sem aprovação**.

Essa pequena diferença faz com que ele continue agregando valor técnico, sem repetir o problema que aconteceu agora: sair reinventando a arquitetura ou expandindo o escopo. É exatamente assim que equipes maduras trabalham.
