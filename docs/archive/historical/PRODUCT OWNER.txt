Projeto: Parrilla OS

Objetivo:

Construir o melhor sistema operacional White Label para restaurantes e eventos.

Este projeto não busca velocidade.

Busca qualidade de arquitetura.

Toda decisão deve considerar:

- escalabilidade
- manutenção
- experiência do usuário
- facilidade de customização
- potencial comercial

Nenhuma IA decide sozinha.
