## Produtos atuais

Nenhuma foto pode ser vinculada com segurança a Batata Rústica, Chorizo Angus, Bife de Tira, Fettuccine Alfredo, Burger +54, Coca-Cola 350ml ou Pudim Artesanal. As fotos de carne são candidatas de categoria, não prova de correspondência com Chorizo Angus ou Bife de Tira.

## Requisitos para novas imagens

- Arquivo mestre com no mínimo 2400 px no lado maior.
- Versões 4:5 para mobile, 16:9 para desktop e 1:1 para cards futuros.
- Produto inteiro dentro de uma área segura central.
- Sem texto, preço, logo promocional ou pessoa reconhecível em destaque.
- Luz quente coerente entre categorias.
- Registro do produto, unidade, data, fotógrafo e autorização.
